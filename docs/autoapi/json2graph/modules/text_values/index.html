json2graph.modules.text_values.warn_if_text_value_is_unsupported(text_shape)

Warn when a legacy Text shape contains a non-empty value field.

OntoUML Vocabulary v1.1.1 represents ontouml:Text as a diagrammatic shape and does not define a data property for content stored directly on that shape. Empty legacy values carry no information and are omitted silently. Non-empty values are also omitted, but produce an explicit warning so that source information is never discarded silently.

Parameters:

text_shape (dict) – Text shape dictionary being decoded.

Return type:

None
