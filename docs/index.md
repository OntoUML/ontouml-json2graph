# ontouml-json2graph

`ontouml-json2graph` transforms OntoUML JSON projects into RDF graphs that use the
[OntoUML Vocabulary](https://w3id.org/ontouml).

See the [project README](https://github.com/OntoUML/ontouml-json2graph#readme)
for installation and command-line usage. The API reference documents the
supported Python library interface.
